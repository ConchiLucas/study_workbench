# 识字组题目效果预览 — 设计

日期：2026-08-29  
状态：已确认  
范围：study-content-admin 识字后台（先做效果，不写题库）

## 目标

在识字**每一组**旁展示本组全部字对应的题目效果；支持「查看效果」进入与孩子端一致的答题样式页。后台只用于预览与验收资产（字图 / 义图 / 读音），**不落库、不接入正式出题计划**。

## 题型（固定三种 · 一律 4 选 1）

| 代号 | 难度 | 题干 | 选项 | 语音 |
|------|------|------|------|------|
| `listen_glyph` | 中等 | 听读音（可点播） | 4 张**字图** | 要（TTS / 已缓存 MP3） |
| `glyph_sense` | 简单 | 看目标**字图** | 4 张**义图** | 不要 |
| `sense_char` | 简单 | 看目标**义图** | 4 个**汉字**（可配字图卡样式） | 可（点播目标字读音） |

干扰项规则：

- 仅从**同组其他字**抽取，凑满 3 个干扰 + 1 个正确 = 4 选项
- 组内不足 4 个「可用资产」的字时：该题型对该字标记为「不可预览」（缺图 / 同组可选项不足），不硬凑跨组
- `glyph_sense` / `sense_char` 要求目标与干扰项具备对应义图；无义图的字跳过该题型或占位说明
- **每次进入效果页 / 换下一题时重新随机**选项顺序与干扰项抽取

覆盖要求：组内**每个字**在后台题目区都要能看到上述三种题型的效果位（有资产则完整渲染，缺资产则占位）。

## 布局

### 组内题目区（管理列表）

每道题一行，三列网格：

| 第 1 列 | 第 2 列 | 第 3 列 |
|---------|---------|---------|
| 题干（听音按钮 / 字图 / 义图） | 选项上 | 选项上 |
| （题干区纵向撑满） | 选项下 | 选项下 |

三种题型按字或按题型分段展示（实现时优先：**按字折叠块**，块内三道题各一行三列），组头提供「查看效果」主按钮。

### 效果页（孩子端样式）

- 独立路由，例如 `/literacy/preview/:moduleCode`
- 视觉对齐 kid-app：进度感、大题干、2×2 选项、对错反馈可本地演示
- 可切换题型筛选或「本组全部字 × 三种题」顺序刷题
- 答题仅本地状态；刷新即重新随机

## 数据与 API

MVP 不新增持久化表。

建议：

- `GET /api/v1/literacy/modules/:moduleCode/quiz-preview`  
  - 输入：可选 `seed`（调试用）；默认服务端或前端每次用新随机  
  - 输出：按字列出三题骨架：`type`、`stem`（char / glyphUrl / senseUrl / speechUrl）、`options[]`（label / glyphUrl / senseUrl / correct）
- 资产 URL 复用现有 literacy chars 的字图 / 义图 / speech 代理接口
- 干扰项与随机可在**前端**用已同步的组内 char 列表完成（更轻）；若随机逻辑希望与日后 kids 共用，再抽到后端同一函数

推荐 MVP：**前端组内随机 + 现有 list API 资产**，效果页不强制新后端接口；若列表页也要服务端一致随机，再补 preview API。

## 非目标（本版不做）

- 写入 workbench `questions` / 计划出题
- 难度调度、错题本、星星结算页（效果页可极简本地对错即可）
- 听写、同音辨析、组词等额外题型
- iframe 嵌入真实 kid-app 计划

## 验收

1. 识字某组展开后，每个字可见三种题型三列布局（或明确占位原因）
2. 「查看效果」进入效果页，布局接近孩子端，选项为 4 且为组内随机
3. 连续两次进入同一组，选项顺序 / 干扰项组合可变
4. 无题库写操作、无计划 API 依赖

## 实现顺序

1. 组内三列题目效果展示（只读，用当前组 chars 资产）
2. 「查看效果」路由 + 孩子端风格交互壳
3. （可选）抽共享 `buildLiteracyPreviewQuestions(chars)` 便于日后 kids 复用
