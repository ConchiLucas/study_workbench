# 最佳例句挖空字段设计

## 目标

为 `public.word_clean_best_sentence` 的每条最佳例句保存可直接用于单词挖空练习的数据。练习答案必须是例句中真实出现的词形，而不是词典原形。

示例：

```text
word: value
sentence: The company values fairness in its hiring process.
cloze_sentence: The company ____ fairness in its hiring process.
cloze_answer: values
```

## 字段

新增两个非空字段：

```sql
cloze_sentence text NOT NULL DEFAULT '',
cloze_answer text NOT NULL DEFAULT ''
```

- `cloze_sentence`：把目标词形替换为 `____` 后的完整英文句子。
- `cloze_answer`：句中实际被替换的文本，保留原始大小写和屈折形式。
- `word` 继续保存词典词条，不重复增加原形字段。

## 定位规则

1. 优先按英文词边界进行大小写不敏感的原词匹配，但答案保留句中的原始文本。
2. 原词未命中时，从带括号、省略号或搭配标记的词条中提取主要英文词元，再识别句中的复数、第三人称、过去式、过去分词、进行时和比较级等词形。
3. 同一句中同一答案词形出现多次时，将所有同形出现位置都替换为 `____`，避免答案仍暴露在句中；`cloze_answer` 仍只保存一次。
4. 只有存在唯一可信词形时才写入。不能唯一定位、候选答案不一致或无法由挖空结果还原原句时，保持两个字段为空并写入失败报告。
5. 正确性判断要求用户输入与 `cloze_answer` 的词形一致；比较时仅忽略大小写和首尾空格，不接受词典原形替代句中变形。

## 数据一致性

- 回填在单个数据库事务中执行，先生成和验证全部结果，再统一更新。
- 每条结果必须满足：答案非空、挖空句含 `____`、挖空句不再暴露同形答案、用答案替换空位可还原原句。
- 增加完整率、失败数、多次挖空数和词形变化数统计，并输出未匹配记录 CSV。
- 最佳例句重新评分导致 `sentence` 变化时，同步重新计算挖空字段，不能保留旧值。

## 实现范围

- 更新 SQL 建表文件和 Python 运行时建表逻辑。
- 新增独立、可测试的词形定位与挖空模块。
- 最佳例句 upsert 时写入新字段。
- 新增一次性幂等回填脚本并在当前数据库执行。
- 回填后验证 22,375 条记录的完整性和原句可还原性；疑难数据不靠猜测写入。

## 非目标

- 本次不创建新的练习页面或答题记录表。
- 本次不改变 `word`、`sentence`、TTS 或评分字段。
- 本次不接受原形作为变形答案的替代值。
