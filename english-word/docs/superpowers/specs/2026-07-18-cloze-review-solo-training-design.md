# 错题挖空复习与单独训练首页设计

## 目标

重构 `rob_english_word_cloze_web` 的启动页，将“按计划复习到期错题”和“自选词库难度训练”拆成两个清晰入口：

- 首页只负责错题挖空复习。
- 单独训练页负责非段位词库难度训练、句子列表和答题结果。
- 用户最后选择的单独训练难度保存到 `users` 表，浏览器不持久化难度。

## 页面结构

### 首页：错题挖空复习

首页标题由“主练习场”改为“错题挖空复习”，启动区域只保留两个按钮：

1. “开始答题”：加载已经到复习时间的错题并进入现有沉浸式答题界面。
2. “单独训练”：进入独立的单独训练页面。

首页不显示难度标签、难度选择、句子列表或答题结果入口。首页可显示本轮到期错题数量；没有到期错题时显示“今天没有需要复习的错题”，禁用“开始答题”，但保留“单独训练”。

### 单独训练页

单独训练页沿用当前启动区的视觉风格，提供：

- 返回错题复习首页。
- 当前词库难度与每轮 10 句提示。
- “选择难度”。
- “句子列表”。
- “答题结果”。
- “开始训练”。

难度选择页完全移除“段位难度”，只保留小学、初中、高中、大学、升学、商务出国、专业和高阶考试等词库难度。首次默认“初中英语”；之后从数据库恢复用户上次选择。

### 答题界面

错题复习和单独训练继续复用现有沉浸式答题界面。前端记录本轮来源模式：

- `review`：退出或本轮结束后返回错题复习首页。
- `solo`：退出或本轮结束后返回单独训练页。

两种模式不互相回退或补题。

## 到期错题数据流

新增明确的到期错题查询，不复用段位难度或普通待答查询：

```text
错题复习首页
  -> GET /api/cloze-practice/tasks/review-due?limit=10
  -> 查询当前用户、当前状态仍为错题且 next_review_time <= NOW() 的题目
  -> 返回本轮最多 10 题
  -> 开始答题
```

查询要求：

- 必须存在当前用户的 `sentence_cloze_review_schedule`。
- `next_review_time` 已到期。
- 题目最近一次答案仍为错误，不能包含已经答对或已掌握题目。
- 按 `next_review_time`、题目 ID 稳定排序。
- 普通待答题、尚未到复习时间的错题和单独训练生成题不会混入。

接口错误时首页显示错误，不回退到其他题源。

## 单独训练难度偏好

### 数据库

直接在 `users` 表增加：

```sql
solo_difficulty_group varchar(64) NOT NULL DEFAULT 'junior'
solo_difficulty_level varchar(64) NOT NULL DEFAULT 'junior'
```

数据库变更脚本使用 `ADD COLUMN IF NOT EXISTS`，并将现有空值回填为 `junior`。用户实体同步增加两个字段。

### 接口

新增两个认证接口：

- `GET /api/cloze-practice/preferences`
  - 返回 `soloDifficultyGroup` 和 `soloDifficultyLevel`。
  - 用户没有有效值时返回并修正为默认 `junior/junior`。
- `PUT /api/cloze-practice/preferences/solo-difficulty`
  - 请求包含 `difficultyGroup` 和 `difficultyLevel`。
  - 使用与难度批次一致的白名单校验。
  - 明确拒绝 `rank`、`rank_current`、空值和未知组合。
  - 保存成功后返回规范化结果。

前端在登录成功、已有 token 恢复会话或页面刷新后调用 GET 接口，把结果放入 React 内存状态。选择新难度时先调用 PUT，成功后更新界面；失败时保留原选择并提示错误。

前端删除 `cloze_practice_difficulty` 的读写逻辑。难度偏好不进入 JWT、不随认证对象写入 `localStorage`，刷新后重新从数据库获取。

## 前端组件边界

为减少当前 `App.tsx` 中重复的启动区 JSX，新增两个聚焦组件：

- `ReviewPracticeLauncher`
  - 输入：到期题目数量、加载状态和两个点击回调。
  - 只渲染错题复习首页启动区。
- `SoloTrainingLauncher`
  - 输入：当前难度、批次进度、加载状态和难度/列表/结果/开始/返回回调。
  - 只渲染单独训练启动区。

难度选项和合法性判断抽到纯函数模块，前端和测试可验证：

- 默认 `junior/junior`。
- 服务器返回未知值时回退默认值。
- 难度选择器中不出现 `rank_current`。

`App.tsx` 继续负责认证、模式状态、远程数据加载、答题覆盖层和错误提示。

## 状态与错误处理

- 到期错题加载中：禁用首页开始按钮并显示加载状态。
- 无到期错题：显示空状态，不请求普通待答题。
- 到期错题接口失败：显示错误，不切换模式。
- 难度偏好读取失败：本次会话使用默认初中英语并提示；不写浏览器缓存。
- 难度偏好保存失败：保留原难度，不开始对应训练。
- 单独训练所选难度无句子：停留在单独训练页并提示。
- 登录过期：沿用现有统一退出逻辑。
- 退出答题：停止句子音频并返回发起答题的模式页。

## 测试

### Java 后端

- 数据库脚本可重复执行，现有用户得到默认值。
- 到期错题查询只返回 `next_review_time <= NOW()` 且最近答案错误的记录。
- 未到期、最近答对、已掌握和普通待答题均被排除。
- GET 偏好返回数据库值或默认值。
- PUT 可保存合法父级/子级词库难度。
- PUT 拒绝段位难度、未知组合和空值。

### React 前端

- 首页只显示“开始答题”和“单独训练”。
- 首页开始操作只调用到期错题接口。
- 无到期错题时开始按钮禁用。
- 单独训练页显示难度、句子列表、答题结果和开始训练。
- 难度选择器不包含段位难度。
- 偏好从服务器初始化，选择后先持久化再更新状态。
- 不再访问 `cloze_practice_difficulty`。
- 两种模式退出答题时返回正确页面。

最后运行 Java 全套测试、React 单元测试、TypeScript 构建与 `git diff --check`，并在 `http://localhost:7003` 验证桌面与窄屏布局。
