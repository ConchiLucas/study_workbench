# 英语单词外部词典、模型、TTS 与对象存储

## 公共词典

- 完形前端会从浏览器直接查询公共英语词典，用于补充音标等展示信息。
- 该能力属于增强体验；跨域、限流或服务不可用时不应阻断登录和答题主流程。

## LLM Provider

- Provider 和模型配置由 Go 管理服务保存或发布，Python Agent 负责实际调用。
- Agent 必须处理超时、限流、非结构化输出和内容不符合约束等失败。
- 文档不保存 API Key、完整请求样本中的隐私数据或供应商凭据。

## MiMo TTS

- Python Agent 负责生成单词或句子音频，Go 与前端负责业务配置、结果展示和播放。
- TTS 成功不代表对象存储写入成功，两阶段状态需要分别记录和排查。

## 对象存储

- 音频可写入 MinIO 或兼容对象存储，并由服务端返回受控访问 URL。
- Endpoint、Bucket、Access Key 和 Secret 只存在于受控配置，不进入文档树。

## 运行时验证

- 分别验证 Provider、TTS、对象存储网络和数据库回写，避免用单个健康检查替代端到端检查。
- 外部能力变化后保留失败码、耗时和重试结果，但日志必须脱敏。
