# 英语抢词业务术语表

| 术语 | 含义 | 主要 Project |
| --- | --- | --- |
| 抢词匹配 | 用户进入匹配队列并形成对战房间的过程 | Vue、Java、Redis |
| 对战房间 | 一局实时游戏的参与者、题目、状态和计时上下文 | Java、Redis |
| 游戏记录 | 完成或结算后的持久化对局及答题结果 | Java、PostgreSQL |
| 错词 | 用户在游戏或练习中答错并进入复习范围的词 | Java、Go、管理端 |
| 掌握词 | 根据业务状态被视为已掌握的用户词汇 | Java、Go、管理端 |
| 完形任务 | 包含句子、挖空项、目标词和难度的练习单元 | 完形前端、Java |
| 到期复习 | 根据复习进度已到下一次练习时间的完形任务 | Java、完形前端 |
| 复习进度 | 用户对目标词或完形项的当前阶段、次数和下一次时间 | Java、PostgreSQL |
| 词库 | 按教材、考试或来源组织的单词集合 | Go、管理端 |
| 清洗单词 | 进入句子补充、质量检查和评分流程的规范化单词 | Go、Agent |
| 清洗句子 | 为目标词生成或整理、等待评分与采用的例句 | Go、Agent |
| 执行任务 | 后台发起并记录步骤、状态、输出和错误的异步工作 | Go、Agent、管理端 |

术语口径变化时，优先修改本表并同步检查 API 字段、页面文案和链路文档。
