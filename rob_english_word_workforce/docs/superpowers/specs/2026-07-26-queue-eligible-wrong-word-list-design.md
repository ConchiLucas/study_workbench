# 可入队错题记录列表与答案列精简设计

## 目标

重构用户端 `/wrong-words` 错题集，使列表统计所有符合造句队列入口条件的错误单词事件，并使用统一的答题明细字段展示。

同时删除用户端和管理后台所有错题、造句及训练结果表格中的“你的答案”展示列，保留“正确答案”。本次只删除展示，不删除数据库中的用户答案，也不修改队列事件负载。

## 可入队错题口径

错题集不再要求记录必须存在 `word_id`，也不再只按单词聚合。每个能够送入造句队列的错误单词事件展示为一行。

### 普通单词答题

数据来自 `game_answer_detail`，记录必须满足：

- 当前登录用户；
- `is_correct = 0`；
- 用户 ID 有效；
- `word_content` 非空。

正式匹配、难度训练和单人训练等所有写入 `game_answer_detail` 的答错入口都计入。

### 挖空答题

数据来自 `sentence_cloze_answer_record` 和 `sentence_cloze_item`，记录必须满足：

- 当前登录用户；
- `is_correct = false`；
- 标准答案数组不为空；
- 目标单词非空。

系统按标准答案与用户答案的相同下标逐词比较，忽略大小写和首尾空白。数组长度不一致时，所有标准答案均视为错误。一次多词挖空中错两个目标单词，列表生成两行。

该判断与 `WrongWordAgentNotificationService` 当前发送队列事件的规则保持一致。

## 用户端接口

新增扁平事件接口，避免直接破坏现有聚合接口和详情接口：

```text
GET /api/wrong-words/events
  ?keyword=
  &sort=recent|count
  &page=1
  &size=20
```

响应包含：

```text
items
total
current
pages
```

每个事件包含：

- `eventKey`：来源类型与来源记录组成的稳定唯一键；
- `word`：来源单词；
- `answeredAt`：答错时间；
- `entry`：入口大类；
- `mode`：入口模式；
- `difficultyLabel`：词库或难度标签；
- `wordDifficulty`：单词难度，可空；
- `costMs`：答题耗时；
- `correctAnswer`：正确答案；
- `sourceType`：`game` 或 `cloze`；
- `occurrenceCount`：当前用户该单词的累计可入队次数。

分页总数按错误单词事件计算，不按去重单词计算。`count` 排序先按 `occurrenceCount` 降序，再按答错时间降序。

保留现有 `/api/wrong-words` 和 `/api/wrong-words/{wordId}/details`，减少对未知调用方的兼容性影响。

## 字段映射

### 普通单词答题

| 展示字段 | 数据来源 |
| --- | --- |
| 来源单词 | `game_answer_detail.word_content` |
| 答错时间 | `game_answer_detail.create_time` |
| 入口/模式 | `game_record.mode` 及训练模式映射 |
| 词库/难度 | `training_difficulty_group`、`training_difficulty_level` |
| 词难度 | `game_answer_detail.word_difficulty` |
| 耗时 | `game_answer_detail.answer_time_ms` |
| 正确答案 | 正确选项对应的中文释义 |

### 挖空答题

| 展示字段 | 数据来源 |
| --- | --- |
| 来源单词 | 当前错误下标对应的标准英文单词 |
| 答错时间 | `sentence_cloze_answer_record.create_time` |
| 入口/模式 | 挖空答题；根据题目来源和作答阶段显示单独训练、待练句子或错题复习 |
| 词库/难度 | 优先使用句子难度标签，没有时显示“外部错题造句” |
| 词难度 | 按来源单词 ID 或英文内容匹配词库；无法匹配时显示 `-` |
| 耗时 | `sentence_cloze_answer_record.cost_ms` |
| 正确答案 | 当前错误下标对应的标准英文单词 |

## 用户端页面

`rob_english_word_front` 的 `/wrong-words` 改为桌面表格和窄屏卡片共用的扁平事件列表，字段顺序为：

1. 来源单词
2. 答错时间
3. 入口/模式
4. 词库/难度
5. 词难度
6. 耗时
7. 正确答案

页面标题副文案改为“可入队错题记录”，数量使用事件总数。保留搜索、最近错误排序、错误次数排序、每页数量和分页。

删除原有按单词聚合的“详情”弹窗入口；同一单词的每次错误已经直接作为独立行展示。

## 删除“你的答案”展示列

以下位置统一删除表头和行数据中的“你的答案”，并调整网格列数和响应式布局：

- 用户端 `/wrong-words` 新列表；
- 用户端训练答题结果；
- 管理后台“用户错题集”独立页面；
- 管理后台用户详情中的“错题集”弹窗；
- 管理后台“用户造句错题集”独立页面；
- 管理后台用户详情中的“造句错题集”弹窗；
- 管理后台“用户造句结果”展开后的来源单词表；
- 管理后台训练答题结果明细。

相关 TypeScript 类型和后端响应可以继续保留用户答案字段，以保持兼容并避免数据丢失；本次只停止渲染。

## 错误与空值处理

- 词难度、词库难度或耗时缺失时显示 `-`；
- 无法识别的模式显示后端原始模式，原始模式也为空时显示 `-`；
- 单条记录部分扩展信息缺失时仍展示，不影响其他记录；
- 接口失败时保留现有错误状态，不回退到旧聚合接口；
- 没有数据时显示“暂无可入队错题记录”。

## 测试

### Java 后端

- 普通答错记录即使 `word_id` 为空，只要单词内容有效也会返回；
- 正确记录、空单词和无效用户不返回；
- 挖空多词答案只拆出实际错误的目标单词；
- 挖空答案数组长度不一致时返回全部标准单词；
- 普通答题和挖空答题可以合并分页，并按统一时间排序；
- `count` 排序使用单词累计事件数。

### 用户前端

- 合同测试验证新接口和七个字段；
- 页面源码不包含“你的答案”；
- 搜索、排序、分页参数保持可用；
- 窄屏卡片仍能完整显示七个字段。

### 管理后台

- 表格合同测试验证所有目标组件不再渲染“你的答案”；
- “正确答案”仍保留；
- 调整后的网格列数与表头、数据行一致；
- 管理后台构建和既有测试通过。

## 不在本次范围

- 不删除或清空任何历史用户答案；
- 不修改造句队列消费者、任务状态或三词成句逻辑；
- 不把列表限制为已成功送达 Python 的事件；列表表达的是“符合入队资格”的源错误事件；
- 不修改挖空复习的立即、7 天和 15 天时间规则。
