# 7003 挖空练习全屏关闭导航设计

## 目标

将 7003 挖空练习的“单独训练”及其子页面统一为全屏页面右上角叉号关闭，移除左上角“返回”按钮，并保证每次关闭只返回一个明确的页面层级。

## 页面层级

1. “错题挖空复习”是 7003 的首页。
2. “单独训练”关闭后回到“错题挖空复习”。
3. “选择难度”“句子列表”“答题结果”关闭后回到“单独训练”。
4. 全屏答题关闭后回到“单独训练”，不退出登录，也不改变已选难度。
5. Escape 键与当前最上层页面的叉号行为一致。

## 实现方案

- 新建共享的 `FullscreenCloseButton` React 组件，统一按钮的无障碍标签、点击行为和右上角样式。
- `SoloTrainingLauncher` 使用共享组件替换原“返回”按钮。
- 三个子页面和全屏答题均使用共享组件，并继续调用现有的局部状态关闭函数。
- 子页面标题与刷新按钮保留，调整头部布局以避免与右上角关闭按钮重叠。
- 不修改路由、接口、数据库或训练数据。

## 验证

- 组件测试验证关闭按钮可访问且触发一次关闭事件。
- 启动器测试验证“单独训练”不再出现“返回”，关闭后调用上层回调。
- 导航契约测试验证三个子页面均使用右上角关闭按钮，且不存在旧的“返回”按钮。
- 运行 7003 前端全部测试和生产构建。
