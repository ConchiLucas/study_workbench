# 7002 前端全屏关闭导航设计

## 目标

统一 `rob_english_word_front`（`http://localhost:7002`）所有按钮进入的二级、三级界面：移除左上角“返回”按钮，使用固定在右上角的 `×` 关闭当前全屏界面并回到明确的上一级界面。

## 统一视觉与交互

- 子界面继续占满整个视口，视觉上作为覆盖上一级内容的全屏弹窗。
- 关闭按钮固定在视口右上角，使用圆形弱边框样式，文字为 `×`。
- 按钮必须有 `type="button"`、`aria-label="关闭"` 和可见的 hover/focus 状态。
- 页面滚动时关闭按钮保持可见，移动端缩小尺寸但仍满足触控区域要求。
- 不再显示左上角返回箭头、返回文字或为其保留的占位区域。
- `Escape` 与点击 `×` 调用同一个关闭函数。
- 已有普通详情弹窗保留点击遮罩关闭；路由级全屏界面不因点击背景而关闭。
- 账号和退出入口只显示在主页，单人训练等全屏子界面不重复显示。

## 页面层级与关闭目标

| 当前界面 | 打开来源 | `×` / Escape 关闭目标 |
| --- | --- | --- |
| 单人训练设置 | 主页“单人训练” | 主页 |
| 难度选择 | 单人训练“难度选择” | 单人训练设置 |
| 今日答题结果 | 单人训练“查看答题结果” | 单人训练设置 |
| 已掌握单词 | 单人训练“已掌握单词” | 单人训练设置 |
| 错题集 | 主页“错题集” | 主页 |
| 对战/训练记录 | 主页统计卡片 | 主页 |
| 记录答题详情 | 记录列表“答题详情” | 记录列表 |
| 记录卡片详情 | 记录列表记录卡片 | 记录列表 |
| 错题详情 | 错题列表“详情” | 错题列表 |
| 游戏结束结果 | 对局/单人训练完成 | 主页 |

路由页面使用显式父级地址，不使用 `router.back()`：记录、错题关闭到 `/home`；答题结果和已掌握单词关闭到 `/home` 并携带 `openTrainingSetup` 状态。这样从刷新、收藏或新标签直接进入页面时，关闭行为仍然确定。

## 组件设计

新增共享组件 `FullscreenCloseButton.vue`：

- 接收可选的 `disabled`、`label` 和附加 class。
- 点击时发出 `close` 事件。
- 组件自身负责统一图标、无障碍属性和基础视觉样式。
- 页面负责决定“关闭到哪里”，组件不直接依赖 router。

新增组合函数 `useEscapeClose`：

- 组件挂载时注册 `keydown`。
- 仅响应 `Escape`，调用传入的关闭函数。
- 组件卸载时移除监听。
- 当页面处于不可关闭状态时，由调用方传入保护后的关闭函数。

## 页面改造

### HomeView

- 单人训练设置从左上角“返回”改为右上角共享关闭按钮。
- 移除子界面的昵称和退出按钮。
- 难度选择从左上角“返回”改为右上角共享关闭按钮。
- Escape 优先关闭最上层难度选择；否则关闭单人训练设置。
- 训练请求处于提交状态时保持现有防重复保护，关闭按钮显示禁用态。

### 路由列表页

- `TrainingAnswerResultsView`、`MasteredWordsView`、`WrongWordsView`、`RecordView` 的头部返回按钮统一替换为右上角关闭按钮。
- 标题和刷新/筛选操作保持原位置，不使用假占位维持布局。
- 页面根容器保证 `min-height: 100vh`，关闭按钮使用固定定位。

### 详情弹窗

- `AnswerDetailModal` 移除左上角返回按钮，使用右上角共享关闭按钮。
- `WrongWordsView` 和 `RecordView` 已有 `×` 的详情弹窗统一样式、无障碍标签和 Escape 行为。
- 关闭详情只回到当前列表，不改变路由。

### GameView

- 游戏结束结果层删除底部“返回首页”按钮。
- 在结果层右上角显示共享关闭按钮，点击或 Escape 调用现有 `goHome`。
- 对局尚未结束时不提供该关闭入口，避免破坏实时对局状态。

## 验证

- 静态扫描源码，确认不再存在页面导航用途的“返回”按钮和 `router.back()`。
- Vue TypeScript 构建通过。
- 为共享关闭按钮、Escape 组合函数和页面关闭目标添加单元测试。
- 在 7002 登录态逐一打开上述界面，确认右上角只有一个关闭按钮，并验证每层关闭目标。
- 在桌面和窄屏视口检查关闭按钮不会遮挡标题、刷新按钮、账号区或滚动内容。
