# 移除 CLI 新增按钮设计

## 目标

管理员后台“模型配置 > 本地 CLI”页面不再提供手动新增 Codex 或 Gemini 配置的入口。现有配置继续支持查看、编辑、启用、设为当前和删除。

## 界面行为

- 删除 CLI 配置列表下方的“新增 Codex”和“新增 Gemini”按钮。
- 当 CLI 配置列表为空时，仅显示“暂无 CLI 配置”，不显示任何新增按钮或新增引导。
- 保留现有“删除配置”按钮。
- 保留现有配置编辑、启用和“设为当前”功能。

## 数据与接口

- 不修改 Go 管理接口。
- 不修改数据库表、已有 Codex/Gemini 配置或全局执行器选择。
- 不禁止通过后端、数据库迁移或后续 AI 修改增加新的 CLI 类型。

## 测试与部署

- 更新前端页面契约测试，确保组件源码不再渲染“新增 Codex”和“新增 Gemini”。
- 运行全部 React Node 测试和生产构建。
- 仅重建并重新部署管理后台前端镜像。
