A 风格修订：按开源闪卡惯例做「一眼认得」

你说之前不够直观——对。我之前画成了「几何隐喻」（圆=火、三角=山），学龄闪卡很少这么干。 GitHub / 儿童闪卡常见做法是：白底上放一个具体物体，像贴纸一样，而不是抽象符号。

alphabet-flashcards · 插画 prompt mq-hanzi-card · 儿童字源卡 + AI 插画 Printable kids flashcards · flat vector
1. 纯白底不要场景、草地、天空铺满
2. 单个主体居中一张图只表达一个意思
3. 粗描边 + 圆角flat cartoon / 填色书感
4. 无字无阴影图上不写汉字；少投影
5. 具象可指认火=火焰，山=山峰，不是色块

落地 prompt 骨架（对齐 alphabet-flashcards）： Create a clean, child-friendly cartoon illustration of [具体物体，例如 a bright orange flame / a green mountain with a snow tip / a single blue water droplet / an open smiling mouth / one large friendly eye / a pink five-petal flower with stem], centered on a pure white background. Flat vector style, thick black outlines, bright solid colors, smooth rounded shapes. No text, no Chinese characters, no shadows, no extra objects, no scenery background.

抽象字（一/大/上）仍要用固定隐喻物（如一根金条、张臂小人、向上箭头），但画法同样遵守：白底、单物、粗边、无字。
