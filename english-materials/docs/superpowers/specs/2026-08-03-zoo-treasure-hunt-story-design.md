# 《The Zoo Treasure Hunt》故事设计

## 目标

为小学英语三年级上册的 63 个目标单词编写一篇有趣的英语冒险故事。故事以 Markdown 格式保存，适合小学三年级学生阅读和复习词汇。

## 输出文件

- 路径：`小学英语/3年级上册/The Zoo Treasure Hunt.md`
- 形式：英文故事，每段后附中文翻译。
- 目标单词在英文正文中使用粗体标记。
- 文末提供 63 词核对表。

## 故事设定

- 题材：动物园寻宝大冒险。
- 主人公带着书包和学习用品前往动物园，在动物朋友的帮助下，根据数字、颜色和身体部位线索寻找宝藏。
- 主人公在寻宝过程中使用或分享不同食物，最终找到宝箱并与家人和动物朋友庆祝。
- 故事氛围有趣、轻松，结局积极温暖。

## 情节结构

1. 主人公收拾书包和文具，与妈妈、哥哥一起出发。
2. 主人公在动物园获得寻宝地图，认识参与寻宝的动物。
3. 主人公依次破解数字、颜色和身体部位线索。
4. 主人公用食物帮助动物并得到最后的提示。
5. 主人公找到宝箱，与家人和动物朋友分享食物。

## 语言要求

- 主要使用小学三年级可理解的短句。
- 优先使用一般现在时、简单祈使句和基础对话。
- 通过重复句型帮助记忆，但避免机械堆砌单词。
- 允许使用少量非目标基础词作为连接词，以保证情节自然。

## 验收标准

- 英文正文自然地覆盖全部 63 个目标词。
- 每个目标词至少出现一次并以粗体标记。
- 核对表列出全部 63 个词，且与正文逐一对应。
- 每段英文后都有意义准确、表达自然的中文翻译。
- 文件可以直接在常见 Markdown 阅读器中正常显示。
